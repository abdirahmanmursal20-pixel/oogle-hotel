OOGLE HOTEL - FILES TO UPLOAD TO GITHUB

Upload ALL files in this folder directly into the ROOT of your GitHub repository.
Do not upload only the ZIP file.

Required files:
- index.html
- hotel-policies.html
- privacy.html
- terms.html
- 404.html
- manifest.webmanifest
- robots.txt
- oogle-logo.webp

After uploading:
1. Click "Commit changes" in GitHub.
2. Copy your repository URL.
3. Paste it into Render > Public Git Repository.
4. Use Publish Directory: .
